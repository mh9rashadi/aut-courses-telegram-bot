# 🎓 ربات تلگرام کورسز امیرکبیر

یه ربات تلگرام **شخصی** برای [courses.aut.ac.ir](https://courses.aut.ac.ir). بدون اینکه هر بار وارد سایت بشی، از
داخل تلگرام درس‌ها، فایل‌ها، فوروم‌ها، تکلیف‌ها و ددلاین‌هات رو می‌بینی، تکلیف تحویل می‌دی و وقتی چیز جدیدی توی
درس‌هات اضافه بشه خبردار می‌شی.

**رایگانه و سرور نمی‌خواد:** روی پلن رایگان Cloudflare Workers اجرا می‌شه. هر کس ربات خودش رو روی اکانت خودش بالا
می‌آره (حدود ۱۰ دقیقه).

> ⚠️ این پروژه غیررسمیه و هیچ ارتباطی با دانشگاه صنعتی امیرکبیر نداره. ربات از همون API رسمی‌ای استفاده می‌کنه که
> اپلیکیشن Moodle گوشی استفاده می‌کنه.

## ✨ امکانات

- 📚 درس‌های ترم جاری (یا همه‌ی ترم‌ها) ← بخش‌ها ← فعالیت‌ها ← دانلود فایل‌ها مستقیم توی تلگرام (تا ۵۰ مگابایت)
- 💬 خوندن فوروم‌ها (مثلاً اطلاعیه‌های استاد)
- 📝 تکلیف‌ها: مهلت، زمان باقی‌مونده، وضعیت تحویل، نمره، فایل‌های پیوست
- 📤 **تحویل تکلیف از تلگرام:** فایل رو برای ربات بفرست، ربات روی کورسز آپلود می‌کنه (و در صورت نیاز ارسال نهایی)
- 🔔 **اعلان خودکار** (هر ۵ دقیقه بررسی می‌شه):
  - محتوای جدید در درس‌هایی که اعلانشون رو روشن کردی (فایل، تکلیف یا فعالیت جدید)
  - یادآوری ددلاین‌ها ۲۴ ساعت و ۳ ساعت قبل
  - اعلان‌های خود کورسز
- 🗓 تاریخ‌ها شمسی و به وقت تهران

## 🔒 امنیت و حریم خصوصی — حتماً بخون

- **فقط از رباتی استفاده کن که خودت ساختی.** ربات با توکن اکانت کورسز تو کار می‌کنه و این توکن به همه‌چیز اکانتت
  دسترسی داره. اگه توکن یا QR ورودت رو به ربات کس دیگه‌ای بدی، اون شخص به اکانت کورسزت دسترسی پیدا می‌کنه.
- ربات فقط به آیدی تلگرام تو (`OWNER_ID`) جواب می‌ده. بقیه فقط پیام «این ربات شخصی است» رو می‌بینن.
- توکن کورسز **رمزنگاری‌شده** (AES-GCM) توی دیتابیس اکانت Cloudflare خودت ذخیره می‌شه. کلید رمز فقط توی
  secretهای Cloudflare خودته. هیچ داده‌ای جای دیگه‌ای نمی‌ره.
- فایل `.dev.vars` که موقع نصب ساخته می‌شه حاوی رمزهای رباتته. توی git نمی‌ره. به کسی نده و پاکش نکن (برای آپدیت لازمه).
- **موقع کمک گرفتن یا گزارش مشکل** (Issue، چت، اسکرین‌شات) این‌ها رو هیچ‌وقت نفرست: توکن BotFather، محتوای
  `.dev.vars`، عکس یا متن QR ورود (`qrlogin=…`) و خط `/settoken …`. فقط کد خطا (مثلاً `ipmismatch`) کافیه. اگه یکی‌شون لو
  رفت، بخش «اگه رمزی لو رفت» در [docs/OPERATIONS.md](docs/OPERATIONS.md) رو انجام بده.

## 🚀 نصب (حدود ۱۰ دقیقه، بدون نیاز به دانش فنی)

**پیش‌نیازها:**
- یه کامپیوتر ویندوزی (مک و لینوکس هم می‌شه؛ پایین‌تر)
- [Node.js](https://nodejs.org/en/download) (نسخه‌ی LTS). اگه نداشته باشی، نصب‌کننده خودش صفحه‌ی دانلودش رو باز می‌کنه.
- یه اکانت رایگان [Cloudflare](https://dash.cloudflare.com/sign-up) (فقط ایمیل؛ کارت بانکی نمی‌خواد)
- تلگرام

**مراحل:**

۱. از بالای همین صفحه دکمه‌ی سبز **Code** ← **Download ZIP** رو بزن و فایل رو از حالت فشرده خارج کن (راست‌کلیک ← Extract All).

۲. توی پوشه‌ای که درومد، روی فایل **`install.cmd`** دوبار کلیک کن. اگه ویندوز هشدار داد، More info ← Run anyway.

۳. یه صفحه‌ی فارسی توی مرورگرت باز می‌شه که قدم‌به‌قدم جلو می‌بره:
   1. ورود به Cloudflare
   2. ساختن ربات تلگرام توی @BotFather (راهنماش توی صفحه هست)
   3. نصب ربات روی Cloudflare
   4. وصل کردن تلگرام (خودکاره؛ گاهی چند دقیقه طول می‌کشه)
   5. ورود به کورسز: از QR پروفایل کورسز عکس می‌گیری و توی صفحه Ctrl+V می‌زنی. **گوشی و کپی کردن توکن لازم نیست.**

۴. توی تلگرام به رباتت `/start` بده و داخل هر درس دکمه‌ی **🔔 روشن کردن اعلان** رو بزن.

> - پنجره‌ی سیاهی که کنار صفحه باز می‌شه رو تا آخر نصب نبند.
> - هر جا خطا داد، خود صفحه می‌گه چی کار کنی. بستن و دوباره باز کردن `install.cmd` هم امنه: کارهای انجام‌شده تکرار نمی‌شن.
> - **VPN لازم نیست:** اگه تلگرام از کامپیوترت باز نشه، ربات از سمت Cloudflare خودش رو به تلگرام وصل می‌کنه.
> - اگه قبلاً اکانت Cloudflare داری که زیردامنه‌ی `workers.dev` نداره، صفحه می‌گه چطور یکی بسازی.

**مک یا لینوکس:** Node.js رو نصب کن، پوشه رو باز کن و توی ترمینال بزن:

</div>

```bash
npm install
npm run installer
```

**نسخه‌ی ترمینالی** (برای کسایی که مرورگر نمی‌خوان): `npm install && npm run setup`

**ورود دوباره به کورسز** (هر چند ماه یک بار که ربات خبر بده): دوباره `install.cmd` رو باز کن؛ همه‌ی مرحله‌ها تیک
خوردن و فقط «ورود به کورسز» رو انجام می‌دی.

> **چرا ورود از کامپیوتر خودت؟** کورسز فقط QRی رو قبول می‌کنه که از همون اینترنتی خونده بشه که QR رو نشون داده. ربات
> روی سرورهای Cloudflare اجرا می‌شه، برای همین فرستادن مستقیم متن QR به ربات معمولاً خطای `ipmismatch` می‌ده.
>
> | خطا | یعنی چی | چی کار کنی |
> |---|---|---|
> | `ipmismatch` | QR از اینترنت دیگه‌ای خونده شده | QR تازه؛ مرورگر و نصب‌کننده هر دو با VPN یا هر دو بدون VPN |
> | `expiredkey` / `invalidkey` | QR منقضی شده یا قبلاً استفاده شده | QR تازه بساز و سریع امتحان کن |

## ❓ سؤال‌های رایج

**هزینه داره؟** نه. مصرف یه نفر خیلی کمتر از سقف پلن رایگان Cloudflare هست.

**توکن منقضی شد چی کار کنم؟** ربات خودش خبر می‌ده. `install.cmd` رو باز کن و فقط مرحله‌ی «ورود به کورسز» رو انجام بده. معمولاً هر چند ماه یک بار پیش میاد.

**چرا بعضی فایل‌ها ارسال نمی‌شن؟** تلگرام به ربات‌ها اجازه‌ی فرستادن فایل بیشتر از ۵۰ مگابایت رو نمی‌ده (خیلی از rarهای
ضبط کلاس بزرگ‌ترن). اون‌ها رو از خود سایت دانلود کن. فایل‌هایی که برای تحویل تکلیف به ربات می‌فرستی هم حداکثر ۲۰ مگابایتن.

**چرا خود ربات عکس QR رو قبول نمی‌کنه؟** خوندن عکس روی پلن رایگان Cloudflare زیادی پردازش می‌خواد، و کورسز QR رو
از IP سرور ربات قبول نمی‌کنه. برای همین ورود از صفحه‌ی نصب روی کامپیوتر خودت انجام می‌شه.

**ربات جواب نمی‌ده.** `npm run webhook -- --info` رو اجرا کن و بخش «Troubleshooting» در
[docs/OPERATIONS.md](docs/OPERATIONS.md) رو ببین.

**آپدیت کنم چطوری؟** نسخه‌ی جدید ZIP رو بگیر، فایل `.dev.vars` رو از پوشه‌ی قبلی بهش کپی کن (رمزهای رباتت توشه) و
`install.cmd` رو باز کن. اگه با git گرفتی: `git pull && npm install && npm run deploy`.

## 🛠 برای توسعه‌دهنده‌ها

TypeScript روی Cloudflare Workers و D1 (SQLite)، **بدون هیچ وابستگی runtime**. کلاینت‌های تلگرام و Moodle دست‌نویس
هستن و تاریخ شمسی با `Intl` ساخته می‌شه.

</div>

```bash
npm run check     # type-check + unit tests
npm run deploy    # deploy to your Cloudflare account
npm run logs      # live logs (or Cloudflare dashboard → Workers → Observability)
```
