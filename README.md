# 🎓 ربات تلگرام کورسز امیرکبیر

یه ربات تلگرام **شخصی** برای [courses.aut.ac.ir](https://courses.aut.ac.ir). بدون اینکه هر بار وارد سایت بشی، از
داخل تلگرام درس‌ها، فایل‌ها، فوروم‌ها، تکلیف‌ها و ددلاین‌هات رو می‌بینی، تکلیف تحویل می‌دی و وقتی چیز جدیدی توی
درس‌هات اضافه بشه خبردار می‌شی.

**رایگانه و سرور نمی‌خواد:** روی پلن رایگان Cloudflare Workers اجرا می‌شه. هر کس ربات خودش رو روی اکانت خودش بالا
می‌آره (حدود ۱۰ دقیقه).

> ⚠️ این پروژه غیررسمیه و هیچ ارتباطی با دانشگاه صنعتی امیرکبیر نداره. ربات از همون API رسمی‌ای استفاده می‌کنه که
> اپلیکیشن Moodle گوشی استفاده می‌کنه.

## ✨ امکانات

- 📚 درس‌های ترم جاری (یا همه‌ی ترم‌ها) ← بخش‌ها ← فعالیت‌ها ← دانلود فایل‌ها مستقیم توی تلگرام (تا ۵۰ مگابایت)
- 💬 خوندن فوروم‌ها (مثلاً اطلاعیه‌های استاد)
- 📝 تکلیف‌ها: مهلت، زمان باقی‌مونده، وضعیت تحویل، نمره، فایل‌های پیوست
- 📤 **تحویل تکلیف از تلگرام:** فایل رو برای ربات بفرست، ربات روی کورسز آپلود می‌کنه (و در صورت نیاز ارسال نهایی)
- 🔔 **اعلان خودکار** (هر ۵ دقیقه بررسی می‌شه):
  - محتوای جدید در درس‌هایی که اعلانشون رو روشن کردی (فایل، تکلیف یا فعالیت جدید)
  - یادآوری ددلاین‌ها ۲۴ ساعت و ۳ ساعت قبل
  - اعلان‌های خود کورسز
- 🗓 تاریخ‌ها شمسی و به وقت تهران

## 🔒 امنیت و حریم خصوصی — حتماً بخون

- **فقط از رباتی استفاده کن که خودت ساختی.** ربات با توکن اکانت کورسز تو کار می‌کنه و این توکن به همه‌چیز اکانتت
  دسترسی داره. اگه توکن یا QR ورودت رو به ربات کس دیگه‌ای بدی، اون شخص به اکانت کورسزت دسترسی پیدا می‌کنه.
- ربات فقط به آیدی تلگرام تو (`OWNER_ID`) جواب می‌ده. بقیه فقط پیام «این ربات شخصی است» رو می‌بینن.
- توکن کورسز **رمزنگاری‌شده** (AES-GCM) توی دیتابیس اکانت Cloudflare خودت ذخیره می‌شه. کلید رمز فقط توی
  secretهای Cloudflare خودته. هیچ داده‌ای جای دیگه‌ای نمی‌ره.
- فایل `.dev.vars` که موقع نصب ساخته می‌شه حاوی رمزهای رباتته. توی git نمی‌ره. به کسی نده.
- **موقع کمک گرفتن یا گزارش مشکل** (Issue، چت، اسکرین‌شات) این‌ها رو هیچ‌وقت نفرست: توکن BotFather، محتوای
  `.dev.vars`، متن کامل QR (`qrlogin=…`) و خط `/settoken …`. فقط کد خطا (مثلاً `ipmismatch`) کافیه. اگه یکی‌شون لو
  رفت، بخش «اگه رمزی لو رفت» در [docs/OPERATIONS.md](docs/OPERATIONS.md) رو انجام بده.

## 🚀 نصب (حدود ۱۰ دقیقه)

**پیش‌نیازها:** یه کامپیوتر با [Node.js](https://nodejs.org) نسخه‌ی ۲۰ یا جدیدتر، و یه اکانت رایگان
[Cloudflare](https://dash.cloudflare.com/sign-up) (فقط ایمیل؛ کارت بانکی نمی‌خواد).

۱. **یه ربات تلگرام بساز:** به [@BotFather](https://t.me/BotFather) پیام بده، `/newbot` رو بزن و توکنی که می‌ده رو نگه دار.

۲. **آیدی عددی تلگرامت رو پیدا کن:** به [@userinfobot](https://t.me/userinfobot) پیام بده.

۳. **پروژه رو بگیر و نصب کن:**

</div>

```bash
git clone https://github.com/mh9rashadi/aut-courses-telegram-bot.git aut-courses-bot
cd aut-courses-bot
npm install
npm run setup
```

<div dir="rtl">

اسکریپت `setup` قدم‌به‌قدم جلو می‌ره: مرورگر رو برای ورود به Cloudflare باز می‌کنه، توکن ربات و آیدی تلگرامت رو
می‌پرسه، رمزها رو می‌سازه، دیتابیس رو درست می‌کنه، ربات رو deploy می‌کنه و به تلگرام وصلش می‌کنه. آخرش اسم و
آدرس Worker رو چاپ می‌کنه (اسمش `aut-courses-bot` هست؛ Workerهای دیگه‌ای که توی داشبورد ساختی به این ربات ربطی ندارن).

> **اکانت Cloudflare تازه:** هر اکانت یه بار باید یه زیردامنه‌ی `workers.dev` انتخاب کنه. اگه نداشته باشی، `setup`
> قبل از ساختن هر چیزی می‌گه و لینک صفحه‌اش رو می‌ده. زیردامنه رو بساز، یه دقیقه صبر کن و دوباره `npm run setup` بزن.
> اجرای دوباره امنه: رمزها و دیتابیس قبلی حفظ می‌شن. هر جای دیگه‌ی `setup` هم خطا داد، مشکل رو حل کن و دوباره اجراش کن.

۴. **وارد کورسز شو:** توی تلگرام به رباتت `/start` بده و بعد:
   - توی کورسز (روی کامپیوتر) برو به **پروفایل** ← **نمایش کد کیوآر**. هر QR فقط **۱۰ دقیقه و یک بار** معتبره.
   - QR رو با دوربین گوشی یا Google Lens اسکن کن و **متن لینک** رو کپی کن. شکلش این‌طوریه:
     `moodlemobile://https://courses.aut.ac.ir?qrlogin=…&userid=…`
   - روی **همون کامپیوتری** که QR رو نشون داده (با همون اینترنت/VPN)، توی پوشه‌ی پروژه بزن:

</div>

```bash
npm run qr-token
```

<div dir="rtl">

   - وقتی پرسید، متن QR رو paste کن و Enter بزن. خطی که چاپ می‌کنه (`/settoken …`) رو برای **ربات خودت** بفرست. تمام!

۵. داخل هر درس دکمه‌ی **🔔 روشن کردن اعلان** رو بزن تا محتوای جدیدش رو خبر بده.

> **چرا از کامپیوتر خودت؟** کورسز فقط QRی رو قبول می‌کنه که از همون IPی تبدیل بشه که QR رو نشون داده. ربات روی
> سرورهای Cloudflare اجرا می‌شه و IPش فرق داره، برای همین فرستادن مستقیم متن QR به ربات معمولاً خطای `ipmismatch`
> می‌ده. (می‌تونی امتحانش کنی، ولی اگه این خطا رو دیدی همون QR رو دوباره نفرست؛ QR تازه بساز و از `qr-token` استفاده کن.)
>
> | خطا | یعنی چی | چی کار کنی |
> |---|---|---|
> | `ipmismatch` | QR از IP دیگه‌ای تبدیل شده | QR تازه، و `npm run qr-token` روی همون کامپیوتر و همون اینترنت |
> | `expiredkey` / `invalidkey` | QR منقضی شده یا قبلاً استفاده شده | QR تازه بساز و سریع امتحان کن |
> | «looks like the example» | متن نمونه‌ی راهنما رو زدی | متنی رو paste کن که گوشیت از QR خودت خونده |

## ❓ سؤال‌های رایج

**هزینه داره؟** نه. مصرف یه نفر خیلی کمتر از سقف پلن رایگان Cloudflare هست.

**توکن منقضی شد چی کار کنم؟** ربات خودش خبر می‌ده. مرحله‌ی ۴ (متن QR) رو تکرار کن. معمولاً هر چند ماه یک بار پیش میاد.

**چرا بعضی فایل‌ها ارسال نمی‌شن؟** تلگرام به ربات‌ها اجازه‌ی فرستادن فایل بیشتر از ۵۰ مگابایت رو نمی‌ده (خیلی از rarهای
ضبط کلاس بزرگ‌ترن). اون‌ها رو از خود سایت دانلود کن. فایل‌هایی که برای تحویل تکلیف به ربات می‌فرستی هم حداکثر ۲۰ مگابایتن.

**چرا عکس QR رو قبول نمی‌کنه و متنش رو می‌خواد؟** خوندن عکس روی پلن رایگان Cloudflare زیادی پردازش می‌خواد. دوربین
گوشی متن QR رو راحت می‌خونه.

**ربات جواب نمی‌ده.** `npm run webhook -- --info` رو اجرا کن و بخش «Troubleshooting» در
[docs/OPERATIONS.md](docs/OPERATIONS.md) رو ببین.

**آپدیت کنم چطوری؟** `git pull && npm install && npm run deploy`

## 🛠 برای توسعه‌دهنده‌ها

TypeScript روی Cloudflare Workers و D1 (SQLite)، **بدون هیچ وابستگی runtime**. کلاینت‌های تلگرام و Moodle دست‌نویس
هستن و تاریخ شمسی با `Intl` ساخته می‌شه.

</div>

```bash
npm run check     # type-check + unit tests
npm run deploy    # deploy to your Cloudflare account
npm run logs      # live logs (or Cloudflare dashboard → Workers → Observability)
```

  poller/               background checks + course snapshot diff
  moodle/client.ts      Moodle web-service client

test/                   vitest unit tests
