# 🎓 ربات تلگرام کورسز امیرکبیر

درس‌ها، فایل‌ها، تکلیف‌ها و ددلاین‌های [کورسز](https://courses.aut.ac.ir) رو توی تلگرام ببین، تکلیف رو از همون‌جا
تحویل بده و هر وقت چیز جدیدی اضافه شد یا ددلاینی نزدیک بود، خبردار شو.

رایگانه، سرور نمی‌خواد و هر کس ربات شخصی خودش رو می‌سازه.

## 🚀 نصب (حدود ۱۰ دقیقه)

**قبلش لازم داری:**
- یه کامپیوتر ویندوزی
- یه اکانت رایگان [Cloudflare](https://dash.cloudflare.com/sign-up) (فقط با ایمیل)

**مراحل:**

۱. بالای همین صفحه روی دکمه‌ی سبز **Code** و بعد **Download ZIP** بزن.

۲. فایل ZIP رو از حالت فشرده خارج کن (راست‌کلیک ← **Extract All**).

۳. توی پوشه‌ای که درومد، روی **`install.cmd`** دوبار کلیک کن.

۴. یه صفحه توی مرورگرت باز می‌شه. فقط کارهایی که می‌گه رو انجام بده؛ همه‌چیز رو قدم‌به‌قدم توضیح می‌ده.

تموم! بعدش توی تلگرام به رباتت `/start` بده.

> اگه Node.js نصب نداشته باشی، خود نصب‌کننده صفحه‌ی دانلودش رو باز می‌کنه. نسخه‌ی **LTS** رو نصب کن و دوباره
> `install.cmd` رو باز کن.

## 🔄 بعداً

- **ربات گفت اتصال به کورسز منقضی شده؟** دوباره `install.cmd` رو باز کن و فقط مرحله‌ی «ورود به کورسز» رو انجام بده.
- **می‌خوای ربات رو حذف کنی؟** روی `uninstall.cmd` دوبار کلیک کن.
- **پوشه‌ی ربات رو نگه دار** و پاکش نکن؛ برای ورود دوباره لازمش داری.

## 🔒 امنیت

- ربات فقط مال خودته و فقط به تو جواب می‌ده.
- **توکن ربات، عکس QR کورسز و فایل `.dev.vars` رو برای هیچ‌کس نفرست** و توی اسکرین‌شات نذار.
- از رباتی که کس دیگه‌ای ساخته استفاده نکن: هر کی ربات رو ساخته باشه به اکانت کورسزت دسترسی پیدا می‌کنه.

> ⚠️ این پروژه غیررسمیه و ربطی به دانشگاه صنعتی امیرکبیر نداره.
